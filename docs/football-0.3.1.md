# Football 0.3.1 / Hub 0.1.20 preview

The original 5v5 lobby now runs a five-player configuration of the same host-owned match engine used by Ultimate Club. Existing lobby codes, readiness, teams, membership checks and friend joins remain. Both formats have a virtual 90-minute match, two halves, a change of ends, kickoff positions, offside, throw-ins, corners, goal kicks, fouls, cards, rare evidence-based VAR/goal-line checks, substitutions and recorded goal replays. The old ten-goal cutoff no longer applies to 5v5. Five-player squads use preset fictional players and seven substitutes; they do not alter the club card collection.

When a keeper owns the ball, opposing players are kept outside the whole of that keeper's penalty area. Teammates retain access. The restriction includes body clearance and a short distribution grace period. It also covers goal-kick preparation. This is a deliberate gameplay aid, independent of normal foul detection.

Hold Space or the left mouse button to charge a shot, then release. The host accumulates charge over 1.2 seconds and caps it at full power; clients cannot submit a charge duration or arbitrary velocity. A tap produces a softer kick. Losing possession, switching the controlled player, leaving the match, a cancelled pointer or window blur clears the charge. Passes remain separate. Both match formats and training show a power meter.

Before a match, select whole-team control or one fixed outfield position. Whole-team control switches to the nearest eligible player and follows passes. Fixed-player control keeps that player selected when passing, pressing Tab or another teammate takes a restart. The other players and every goalkeeper use AI. In the 5v5 lobby, separate connected controllers never control the same player simultaneously. If all four outfield slots are occupied, an additional team member observes; goalkeepers remain AI.

5v5 input and simulation are driven by a dedicated bounded timer so a covered/background host window cannot stretch a celebration or replay into minutes. Rendering remains separate. The existing session and membership checks validate input; the host selects players, computes charge and owns substitutions and results. Inputs have monotonic sequence numbers. Guest snapshots cannot change the host's result.

Procedural WebAudio adds crowd ambience, kicks/passes, saves, tackles, whistles, review tones, goal celebrations and the final whistle. The first user interaction unlocks audio. The existing sound-volume preference and a new crowd toggle are respected. A shared event serial prevents sound repeats from network snapshots and replays. The game requires no remote sound downloads.

Pack quantities rise by distinct price tier. Kickoff (750 ZF) has 3, Backline (1600) 4, Rising Stars (2000) 5, Playmakers and Goal Hunters (2400) 6, Elite Nights (5000) 7, Starlight (12000) 9. Prices and per-card rarity probabilities remain unchanged. The server determines quantity, enforces capacity using that quantity and charges once. Existing receipts retain their original cards; consumed promotional openings stay consumed. New test openings use the new quantities. Nine-card reveals fit a 920px viewport, including reduced-motion mode.

The server change is generated by `scripts/football-pack-upgrade-sql.cjs`. It updates the canonical pack catalog and guarded private RPC functions without recreating user inventories, refilling grants or changing the shared Zone Hub wallet. Supabase CLI migration commands use the documented telemetry opt-out variables; the CLI is used only to create a local migration file.

Validation includes engine invariants for both team sizes, host-timed shot strength and cancellation, keeper-area ownership in both halves, fixed-player selection, financial idempotence and preserved receipts, actual desktop sound/volume nodes, a full bot match, two SDK clients through the original 5v5 lobby, Ultimate Club regression checks, nine-card offline openings, and laptop PL/EN controls. The preview workflow also builds Windows and tests an installed upgrade from Hub 0.1.13.
